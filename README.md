# Dramos trikampio savirefleksija

Trumpas savirefleksijos įrankis apie elgesio tendencijas konfliktinėse situacijose.

Jis padeda pastebėti, kuris Karpmano dramos trikampio vaidmuo dažniau įsijungia kylant įtampai:
- **Auka**
- **Gelbėtojas**
- **Persekiotojas**

Rezultatas nėra asmenybės etiketė. Tas pats žmogus skirtinguose santykiuose ar situacijose gali pereiti iš vieno vaidmens į kitą.

Įrankis taip pat pasiūlo konstruktyvesnę kryptį: daugiau pasirinkimo ir atsakomybės, daugiau įgalinančio palaikymo ir pagarbaus iššūkio.

## Svarbu

Tai nėra oficialus Stephen Karpman testas ir nėra diagnostinis ar klinikinis instrumentas. Klausimynas yra savarankiška edukacinė adaptacija, skirta savistabai ir refleksijai.
